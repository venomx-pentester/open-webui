Live Agent Sidebar

Interactive mockup of the restructured Target Status Sidebar. Click the state buttons on the left to simulate different phases of a live VenomX pentest run.

What changed from the current sidebar:

  • Run Info card — shows target IP, run ID, and live status badge instead of generic "Targets" counters
  • Dispatch pipeline — replaces abstract "stages" with real specialist names (recon, web, smb, auth, vuln) and their status
  • Live activity feed — real tool execution events (nmap, nikto, gobuster, hydra) with timing data, replacing mock progress messages
  • Phase awareness — pause on Phase 1 boundary with a confirm action, matching the agent's two-phase flow
  • Progress from dispatch count — progress bar reflects actual completed dispatches instead of heuristic guesses

Event types streamed from the agent runner:

  • run_start — agent begins
  • dispatch — specialist assigned
  • tool_start / tool_result — tool execution
  • specialist_result — specialist finished
  • phase_complete — Phase 1 boundary
  • run_complete — final report
